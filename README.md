<h1 align="center">Aero Download Manager</h1>

<p align="center">多线程下载 · BitTorrent · 内置浏览器 · Material You</p>

> **开发中**：应用代码在 `dev` 分支开发与测试，测试通过后合并到 `main`。
>
> - `dev`：完整的 Flutter 应用源码；推送即由 GitHub Actions 构建 Debug APK，并发布 Pre-release 供下载安装。
> - `main`：稳定分支；合并后由 `Android Release` 工作流构建并发布正式 Release。

## 计划支持

- Android 7.0+、Windows 10+、Linux (GTK3)
- HTTP 多线程分段下载、断点续传、限速、队列
- BitTorrent（.torrent / magnet）
- 内置浏览器下载拦截
- Material 3 + 莫奈取色

构建与使用说明见 `dev` 分支的 README。
